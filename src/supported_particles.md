# List of supported particles
Haddock3 supports (i.e., can process automatically including topology generation, rebuilding of the missing atoms, and point mutations) various carbohydrates, ions, co-factors and a plethora of the modified amino acids - you can check a complete list below.

### Supported carbohydrates
* A2G: 2-N-acetyl-alpha-D-galactopyranose (alpha-GalNAc) - alpha anomer of NGA
* ABE: alpha-D-Abequopyranose
* BDP: beta-D-glucoronic acid
* BGC: beta-D-glucopyranose
* BMA: beta-D-mannopyronose
* FCA: alpha-D-fucopyranose
* FCB: beta-D-fucopyranose
* FUC: alpha-L-fucopyranose
* FUL: beta-L-fucopyranose
* GAL (GLB): beta-D-galactopyranose
* GLA: alpha-D-galactopyranose
* GLC: alpha-D-glucopyranose
* GCS: 2-N-beta-D-glucopyranose (glucosamine)
* GXL: alpha-L-galactopyranose
* MAG: 2-N-Acetyl-beta-D-glucopyranose + Methyl at O1
* MAN: alpha-D-mannopyranose
* MMA: methyl alpha-D-mannopyranoside
* NAA: 1-O-methyl-2-N-Acetyl-alpha-D-glucopyranose
* NAG: 2-N-acetyl-beta-D-glucopyranose
* NAM: 1-O-methyl-2-N-Acetyl-beta-D-glucopyranose
* NDG: 2-N-acetyl-alpha-D-glucopyranose
* NGA: 2-N-acetyl-beta-D-galactopyranose
* NGM: 1-O-methyl-2-N-Acetyl-alpha-D-galactopyranose
* RAM: alpha-L-rhamnopyranose
* SIA: alpha-N-acetyl neuraminic acid
* SIB: beta-N-acetyl neuraminic acid
* XYP: beta-D-xylopyranose
* XYS: alpha-D-xylopyranose

Carbohydrates should be provided with record **HETAM**, e.g.:
```
HETATM    9  C1  NAG B 102     171.992  99.750 236.168  1.00 10.00           C
```

### Supported glycosidic and glycan-protein linkages

Linkages do **not** have to be declared in the configuration file: the topology
module `[topoaa]` detects them from the input coordinates and applies the
corresponding patch. A linkage is created when the anomeric carbon of the donor
residue lies within **2 Å** of the acceptor oxygen, so the glycan must be
provided with a chemically sensible geometry (for example as generated by the
[GLYCAM webserver](http://glycam.org/). Note that the glycan residue code naming outputed by GLYCAM may not match the HADDOCK3 one and therefore potentially requires renaming: see [the haddock3 protein-glycan tutorial](https://www.bonvinlab.org/education/HADDOCK3/HADDOCK3-protein-glycan/)).

| Linkage | From (anomeric carbon) | To | Patch |
| --- | --- | --- | --- |
| beta(1,2), beta(1,3), beta(1,4), beta(1,6) | C1 of a beta-anomer: BGC, GAL, BMA, NAG, NGA, FUL, FCB, XYP, BDP, GCS | O2, O3, O4, O6 of any supported sugar | B12, B13, B14, B16 (B12L, B13L, B14L, B16L for FUL) |
| alpha(1,2), alpha(1,3), alpha(1,4), alpha(1,6) | C1 of an alpha-anomer: GLC, GLA, MAN, NDG, A2G, FCA, XYS, ABE, and the L-sugars FUC, RAM, GXL | O2, O3, O4, O6 of any supported sugar | A12, A13, A14, A16 (A12L, A13L, A14L, A16L for FUC, RAM, GXL) |
| alpha(1,1) | GLC C1 | GLC O1 | A11 |
| alpha(2,3) | SIA, SIB C2 | O3 of GAL, NGA, A2G | A23 |
| alpha(2,6) | SIA, SIB C2 | O6 of GAL, NGA, A2G | A26S |
| alpha(2,8) | SIA, SIB C2 | SIA, SIB O8 | A28S |
| N-glycan | C1 of NAG, NGA, NDG, BGC, GCS | ASN ND2 | B1N |
| O-glycan | C1 of NAG, NGA, NDG, BGC, GCS | THR OG1, SER OG | B1T, B1S |

Notes:

* The residues whose O1 carries a methyl rather than a hydroxyl - MAG, NAM,
  NAA, NGM and the methyl mannoside MMA - are excluded as the donor of a (1,x)
  linkage, since there is no anomeric hydroxyl to substitute. They can still be
  the acceptor.
* The L-sugars FUC, RAM and GXL take the `A1xL` patches, which mirror the
  anomeric improper of `A1x`, as their configuration at C1 is the mirror image
  of the corresponding D-sugar.
* The N- and O-glycan patches force the **beta** anomer. A PDB file in which an
  alpha residue such as NDG is linked to ASN, THR or SER is most often an
  incorrect anomer assignment and will be built as the beta anomer.
* `A26S` with A2G as the acceptor corresponds to sialyl-Tn,
  SIA alpha(2,6) alpha-GalNAc.

Ions should be provided with their charge and a **HETAM** flag. Residue name should contain the absolute charge (e.g. ZN2) while atom name should have the exact charge (e.g. ZN+2), e.g.:
```
HETATM 3833 ZN+2 ZN2 A  42      21.391  -8.794  33.944  1.00 24.37          ZN  
```

## Supported co-factors
The following co-factors are defined using HADDOCK's internal parameters:
* HEB: Heme B, [open pdb example](https://raw.githubusercontent.com/haddocking/haddock3/refs/heads/main/src/haddock/cns/toppar/hemeB.pdb)
* HEC: Heme C, [open pdb example](https://raw.githubusercontent.com/haddocking/haddock3/refs/heads/main/src/haddock/cns/toppar/heme.pdb)

Co-factors should be provided with record **HETAM**, e.g.:
```
HETATM    1  FE  HEB   500       3.565   0.487   0.949  1.00 15.00          
```
For the other co-factors, HADDOCK3 will try to generate the topology and parameters automatically, using the PRODRG server - do add `autotoppar = true` to the [`[topoaa]`](./modules/topology.md#topoaa-module) to enable this option. This works with co-factors bound to a protein, and with several different co-factors in the same structure.
If the co-factor is not available in PRODRG, you will have to [generate and provide the topology and parameters yourself](./structure_requirements.md#dealing-with-non-standard-molecules).

    Atoms: N,HN,CA,HA,CB,HB1,HB2,CG,OD1,OD2,HD2,C,O
